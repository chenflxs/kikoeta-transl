# 功能索引

按功能定位当前实现代码。路径均相对于仓库根目录；对应应用 `0.5.0+10`、内置 GalTransl `8.4.2`。使用说明见 [README](../README.md)，协议与请求示例见[网络接口](网络接口.md)。

## 入口与界面

| 功能 | 位置 | 说明 |
| --- | --- | --- |
| Flutter 应用与页面导航 | `app/lib/main.dart` | 启动应用、侧边栏、最近页导航及页面切换。 |
| 系统托盘与窗口生命周期 | `app/lib/main.dart` | 最小化时隐藏窗口，提供显示窗口、停止任务和退出菜单。 |
| 应用状态与任务控制 | `app/lib/app_state.dart` | 保存设置、串行写入变更、注册页面离开时的自动保存，并创建任务和轮询任务状态。 |
| HTTP 客户端 | `app/lib/services/engine.dart` | 调用本地 engine API。 |
| 任务页 | `app/lib/pages/task_page.dart` | 导入文件、阶段开关、任务进度、停止工作流与导出日志；没有独立的暂存恢复按钮。 |
| 模型页 | `app/lib/pages/models_page.dart` | 发现并选择 ASR、强制对齐和本地 GGUF 模型；分别配置矫正与翻译使用在线服务或本地 Llama。 |
| 听写参数页 | `app/lib/pages/params_page.dart` | 响应式参数分组、CrispASR 命令模板编辑，包括 VAD、强制对齐及切分选项；模板编辑器独立保存滚动位置。 |
| 模型参数页 | `app/lib/pages/model_params_page.dart` | 配置矫正、翻译 Prompt 与请求参数。 |
| 字典页 | `app/lib/pages/dict_page.dart` | 选择和编辑 GalTransl 字典。 |
| 输出页 | `app/lib/pages/output_page.dart` | 设置输出目录及六种 LRC / SRT 预设；配置 LLS 自动同步，逐文件推送已有缓存并显示进度和失败详情。 |
| 设置页 | `app/lib/pages/settings_page.dart` | 设置工具路径、代理和远程访问；提供项目仓库链接与 GitHub 最新发布版本检查。 |
| 最近页 | `app/lib/pages/recent_page.dart` | 查看任务状态、成果文件和缓存大小；打开成果、清理 GalTransl 缓存、删除单条或全部记录，保留已记录的导出成果。 |
| 设置草稿 | `app/lib/settings_draft.dart` | 页面草稿与保存状态。 |
| 公共 UI 与主题 | `app/lib/widgets.dart`、`app/lib/theme.dart`、`app/lib/services/theme_reveal.dart` | 页面公共组件、配色、主题切换动画。 |
| Windows 窗框 | `app/lib/widgets/windows_frame.dart` | 桌面窗口标题栏及控制按钮。 |

模型、听写参数、模型参数、输出与设置页在切换导航时会自动保存未提交的改动；保存失败会停留在原页。任务页开关与字典编辑器仍按原有方式即时保存。设置写入由 `app/lib/app_state.dart` 串行处理，避免并发保存覆盖。

## 服务与任务

| 功能 | 位置 | 说明 |
| --- | --- | --- |
| HTTP API 与服务生命周期 | `engine/server.py` | 本地桌面端 API、受认证保护的远程 API、健康检查与服务生命周期。 |
| 最近结果与工作缓存接口 | `engine/server.py`、`engine/kt/recent.py` | 本机 `/api/recent` 查询、删除单条 / 全部记录；`/{job_id}/cache` 只清理 GalTransl 缓存，记录删除还清理其他工作文件并保留已记录成果。 |
| 网络接口参考 | `docs/网络接口.md` | 远程 `/api/v1` 的认证、任务、事件、下载和缓存接口；也列出本地桌面端接口范围。 |
| 远程文件下载 | `engine/kt/download.py` | 接收任务中的 HTTP/HTTPS `url`，下载到任务临时目录并在任务结束后清理。 |
| 命令行 | `engine/kt/__main__.py` | `kt serve` 与 `kt run` 命令。 |
| 单工作流任务管理 | `engine/kt/jobs.py` | 创建、取消、暂存、显式恢复及相同请求匹配恢复；一次只运行一个工作流，无等待队列。 |
| 持久化检查点 | `engine/kt/job_checkpoint.py` | 原子写入 `.checkpoint.json`，重启加载可恢复任务为 `paused`；已结束任务删除检查点。 |
| 任务事件 | `engine/kt/events.py` | 向界面和 API 提供状态、日志事件。 |
| 任务取消 | `engine/kt/cancellation.py` | 在管线阶段检查取消信号，并终止转码、ASR 子进程。 |
| kikoeta 歌词缓存 | `engine/kt/kikoeta_cache.py` | 为带曲目缓存信息的已完成 kikoeta 任务保存 LRC，最多保留 5 个任务，并提供查询和下载。 |
| Kikoeta-LLS 同步 | `engine/kt/lls_sync.py`、`app/lib/pages/output_page.dart` | 自动上传成功的 Kikoeta 任务产物；手动推送保留的 LRC 缓存，使用独立的 12 位密钥或上传账号密码。 |
| 最近任务索引 | `engine/kt/recent.py` | 为已启用翻译的任务记录成果文件位置，统计 GalTransl 工作缓存并按任务清理缓存目录。 |
| 设置读写 | `engine/kt/settings.py` | 读写 `engine/data/settings.json`，合并任务级覆盖设置。 |
| 数据模型 | `engine/kt/models.py` | 任务、阶段、字幕条目和各类设置模型。 |

远程客户端可通过受 Basic Auth 保护的 `POST /api/v1/jobs` 传入 HTTP/HTTPS 下载地址或 Base64 文件。完整的请求、长轮询事件、输出下载和缓存协议见[网络接口文档](网络接口.md)。

## 处理管线

| 阶段 | 位置 | 说明 |
| --- | --- | --- |
| 管线编排 | `engine/kt/pipeline.py` | 判断媒体或字幕输入，并按顺序执行各阶段。 |
| 阶段计划 | `engine/kt/stages_plan.py` | 根据输入类型和开关生成进度阶段。 |
| 字幕解析 | `engine/kt/subtitle.py` | 解析 SRT、LRC、VTT、ASS、SSA，提取作品号。 |
| 媒体转码 | `engine/kt/stages/transcode.py` | 调用 ffmpeg 转为 16 kHz 单声道 WAV。 |
| ASR 听写 | `engine/kt/stages/asr.py` | 组装并执行 CrispASR 命令、读取结果；支持强制对齐参数生成词级时间戳。 |
| ASR 文本清理 | `engine/kt/stages/asr_cleanup.py` | 处理重复符号，保留需复核的文本，报告写入任务 `gt/reports/`。 |
| 听写矫正 | `engine/kt/stages/correct.py` | 按配置通过在线 OpenAI 兼容接口或本地 Llama 修正字幕文本。 |
| 矫正报告 | `engine/kt/stages/correction_result.py` | 记录修改前后文本、待回听条目和时间轴问题，不作为下载成果。 |
| 翻译 | `engine/kt/stages/translate.py` | 创建 GalTransl 工作区并执行翻译；本地模式复用本地 Llama 会话。 |
| 翻译检查与记录 | `engine/kt/stages/translation_result.py`、`engine/kt/stages/translate.py` | 检查疑似漏译并最多逐条补译 3 次；仍有问题则追加输出目录的 `未翻译记录.txt`，列入成果。 |
| 字幕导出 | `engine/kt/stages/export.py` | 导出目标语言单语、译文优先双语或原文优先双语的 LRC / SRT。 |
| 临时文件清理 | `engine/kt/cleanup.py` | 清理转码、ASR 等中间产物。 |

## 数据目录与验证

| 位置 | 用途 |
| --- | --- |
| `engine/data/settings.json` | 本机设置，含模型和服务凭据，不提交版本控制。 |
| `engine/data/kikoeta_cache/` | 最近最多 5 个成功 Kikoeta 任务的 LRC 副本与索引。 |
| `engine/work/{job_id}/.checkpoint.json` | 暂存恢复所需输入、设置和结果快照，可能包含凭据。 |
| `engine/work/{job_id}/.recent.json` | 最近翻译结果索引，保存成果路径。 |
| `engine/work/{job_id}/{序号}_{文件名}/gt/` | GalTransl 工作缓存及 `reports/` 复核报告。 |
| `engine/work/cli/` | CLI 工作目录，不经过 HTTP 任务管理器。 |
| `engine/checks/galtransl_integration_check.py` | 用模拟 OpenAI 服务检查内置 GalTransl 集成，不代表真实模型质量验证。 |
| `engine/checks/job_resume_check.py` | 工作流暂存、恢复和检查点验证。 |
| `engine/checks/fixtures/kikoeta_queue_server.py` | Kikoeta 队列联调使用的模拟服务。 |

独立 Kikoeta 歌词缓存由 `engine/kt/kikoeta_cache.py` 管理，最多保留 5 个成功任务的 LRC；“最近”页的删除操作不清理它。`test/` 与 `tests/` 目录仅供本地验证，由 `.gitignore` 排除；上表中的 `engine/checks/` 则纳入版本控制。
